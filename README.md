# Gaggle Report (archived)

**gagglereport.org is closed.** The website is no longer online, and this
repository is kept as a read-only archive.

Gaggle Report was a community site for the free flying community, built to
collect and discuss paragliding accident and fatality reports, along with the
pilots' proposals for improving safety.

## What is archived here

This repository holds the site's code: a Drupal site with the custom `pilots`
module (`modules/pilots`) and the `union_custom` theme (`themes/union_custom`).

It does **not** contain:

- **The database** (reports, user accounts, comments, votes, form
  submissions). A full backup taken on 18 September 2026 is kept privately by
  the site owner, [Julien Garcia](https://github.com/julien66). It holds
  personal data, so it is not published here.
- **Uploaded files** (images and attachments from `sites/default/files`).
- **Site settings** (`sites/default/settings.php`), which are excluded from Git.
